# 扩展方块形状 · Blockus 联动

简体中文 · [English](./README.en.md)


这是扩展方块形状的 Blockus 联动。安装后，Blockus 建材可以像主模组里的原版材质一样，使用更多形状来搭建墙面、楼梯和建筑边缘。

## RongMC 26.3 版本的改动

本版将原有形状与配方适配到 Fabric 26.3 的注册和资源格式。Blockus 联动使用该版本的主模组及 Blockus。

## 安装

在 [GitHub Releases](https://github.com/OpenRongMC/Extended-Block-Shapes-Blockus/releases/tag/v3.2.2) 下载 **v3.2.2**。使用 Minecraft Java **26.3**、**Fabric** 和 **Java 25**。 依赖 [Fabric API](https://modrinth.com/mod/fabric-api)、[Extended Block Shapes](https://github.com/OpenRongMC/Extended-Block-Shapes)、[Blockus](https://modrinth.com/mod/blockus)。 将发行 JAR 放进实例的 `mods/` 目录。 这是联动子模组，两端须同时有 Blockus、Extended Block Shapes 与本扩展。选择三个项目都支持的 Minecraft 26.3 发行。
