# Extended Block Shapes · Blockus

[简体中文](./README.md) · English

Extends Blockus materials to more building shapes supplied by Extended Block Shapes.

## Download and installation

- Version · [v3.2.2](https://github.com/OpenRongMC/Extended-Block-Shapes-Blockus/releases/tag/v3.2.2) (Release)
- Release asset · `rongmc-extshape_blockus-fabric-3.2.2.mc26.3.jar`
- Runtime · Minecraft Java 26.3, Fabric, Java 25
- Fabric mod ID · `rongmc_extshape_blockus`
- Dependencies declared by the JAR · [Fabric API](https://modrinth.com/mod/fabric-api), `blockus` `>=2.18.2`, [`rongmc_extshape`](https://github.com/OpenRongMC/Extended-Block-Shapes) `>=3.2.0`

Place the release JAR in the instance’s `mods/` directory. This integration requires Blockus, Extended Block Shapes and this addon on both sides. Choose releases of all three targeting Minecraft 26.3.

## How to try it

Use a Blockus material to look up a matching stair or other variant, then test placement and orientation. Include all three JAR versions in reports about missing content or registration failures.
