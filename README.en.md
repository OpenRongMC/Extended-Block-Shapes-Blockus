# Extended Block Shapes · Blockus

[简体中文](./README.md) · English


The Blockus integration brings Extended Block Shapes to Blockus materials, making the extra building shapes available for walls, stairs and building edges.

## What changed in the RongMC 26.3 port

The port adapts existing shapes and recipes to Fabric 26.3 registration and resource formats. The Blockus integration uses matching builds of Blockus and the core mod.

## Installation

Download **v3.2.2** from [GitHub Releases](https://github.com/OpenRongMC/Extended-Block-Shapes-Blockus/releases/tag/v3.2.2) for Minecraft Java **26.3** on **Fabric** with **Java 25**. Dependencies include [Fabric API](https://modrinth.com/mod/fabric-api), [Extended Block Shapes](https://github.com/OpenRongMC/Extended-Block-Shapes), [Blockus](https://modrinth.com/mod/blockus). Place the release JAR in the instance’s `mods/` directory. This integration requires Blockus, Extended Block Shapes and this addon on both sides. Choose releases of all three targeting Minecraft 26.3.
